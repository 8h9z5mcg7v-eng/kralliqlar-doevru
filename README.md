# Krallıqlar Dövrü

Bu layihənin 3D krallıq qurma mühərriki **Hexkingdom** açıq mənbəli layihəsinin MIT lisenziyası ilə yayımlanan kodundan uyğunlaşdırılıb.

- Orijinal layihə: https://github.com/Leks2000/Hexkingdom
- Lisenziya: MIT — bu repoda `LICENSE` faylına baxın.
- Oyun: https://8h9z5mcg7v-eng.github.io/kralliqlar-doevru/

Məqsəd: Azərbaycan dilində orta əsr krallığı qurmaq, torpaq sahələrini açmaq, tikililər yerləşdirmək və iqtisadiyyatı inkişaf etdirmək. Orijinal layihənin müəlliflik/lisenziya bildirişləri saxlanılır. Bu, Clash of Kings-in kodu və ya rəsmi məhsulu deyil.
