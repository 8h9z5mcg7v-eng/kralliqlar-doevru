# Kazarmanı iPhone-dan yükləmə

Hazırda seçilmiş namizəd: Wolfhold Barracks — Medieval Fantasy Buildings Sampler.

## 1. Model paketini endir
1. Safari-də https://literock-studios.itch.io/medieval-buildings-sampler səhifəsini aç.
2. Download düyməsi ilə ZIP paketini endir.
3. iPhone-da Files → Downloads bölməsinə keç və ZIP faylına toxunaraq arxivdən çıxart.

## 2. Düzgün GLB faylını tap
1. Açılmış qovluqda Wolfhold Barracks üçün olan `.glb` faylını tap.
2. Eyni modelin FBX və preview şəkillərini deyil, məhz GLB faylını seç.
3. Fayl adını `barracks.glb` et.

## 3. GitHub-a əlavə et
1. GitHub-da `8h9z5mcg7v-eng/kralliqlar-doevru` reposunu aç.
2. `buildings/barracks` qovluğuna daxil ol.
3. Add file → Upload files seç və `barracks.glb` faylını yüklə.
4. Commit changes et.

**Vacib:** GitHub-un brauzer üzərindən yükləmə limiti 25 MB-dır. GLB faylı bu həddi keçirsə, yükləməni zorlamadan dayandır; başqa ötürmə üsulu seçəcəyik.

## 4. Oyuna qoşulma mərhələsi
Fayl repoya düşəndən sonra əvvəlcə GLB-nin həndəsəsini, ölçüsünü və materiallarını yoxlamaq lazımdır. Hazırkı xüsusi oxuyucu PBR teksturaları və LOD-ları tam dəstəkləmir. Buna görə faylın repoya yüklənməsi onun avtomatik oyunda görünməsi demək deyil.

## Lisenziya
Müəllif paketi kommersiya və qeyri-kommersiya oyunlarında istifadəyə icazə verir, lakin modelin özünü ayrıca satmaq və ya yenidən yaymaq qadağandır. Paketdəki README/lisenziya qeydini də saxla.
