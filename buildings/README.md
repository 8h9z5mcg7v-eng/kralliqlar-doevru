# 3D bina modelləri

Bu qovluq oyunda istifadə ediləcək GLB 2.0 modelləri üçündür.

## Qaydalar
- Hər bina ayrıca qovluqda saxlanılır.
- Əsas model faylının adı aşağıdakı manifestdə göstərilən adla eyni olmalıdır.
- Model mümkün olduqda PBR materialları ilə, metrə uyğun ölçüdə və pivotu binanın dibində hazırlanmalıdır.
- Yalnız kommersiya istifadəsinə açıq və lisenziyası yoxlanmış modellər əlavə edilməlidir.
- Modelin müəllif/lisenziya məlumatını həmin bina qovluğunda LICENSE.txt faylında saxlayın.

Hazırkı GLB oxuyucu GLB 2.0 geometriyasını, node transformlarını və əsas material rənglərini oxuyur. Xarici tekstura/PBR xəritələri hələ tam dəstəklənmir.
