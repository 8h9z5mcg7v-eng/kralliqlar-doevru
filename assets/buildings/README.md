# Buildings assets

Bu qovluğa oyunda istifadə olunacaq hazır 3D bina modellərini yüklə.

Tövsiyə olunan format: .glb (teksturalar faylın daxilində olsun).
Fayl adları: barracks.glb, stable.glb, farm.glb və s.

Qeyd: Hazırkı oyun mühərrikinə GLB yükləyici inteqrasiyası tələb oluna bilər. Faylın bura yüklənməsi onun avtomatik oyunda görünməsi demək deyil.
